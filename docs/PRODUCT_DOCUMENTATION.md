# Stock Bazaar product documentation

## Purpose

Stock Bazaar is an educational stock-monitoring and market-analysis web application for Bangladesh. It helps users organise research and their own records; it is not a brokerage, trading or personalised-advice service.

## Main features

- **Market screener:** browse enabled exchange stocks, technical analysis, sector context and comparisons.
- **Watchlist and alerts:** follow selected securities and configure notifications.
- **Portfolio and investor journal:** add holdings manually or import a CSV; keep transactions, investment thesis, target, invalidation/risk notes and reviews.
- **Research signals:** view calculated signals, model context and reliability information. These are research estimates, not trade instructions.
- **Language and appearance:** use the navigation menu to select English or বাংলা, and use the Dark/Light control to select a browser-saved colour theme.
- **Data freshness:** authenticated pages show the timestamp of the most recent successful market-data update in the fixed footer.

## Getting started

1. Create an account and sign in.
2. Use **Stocks** to explore available securities and add relevant stocks to your watchlist.
3. Open **Portfolio** to create a portfolio. Add a holding, transaction or CSV import.
4. Write an investor-journal entry with your thesis, target and invalidation point before or after a trade.
5. Configure alerts only after reviewing the relevant data and risk information.

## Important limitations

Market data can be delayed, incomplete or corrected. Technical signals, forecasts, machine-learning outputs and historical backtests can be wrong and do not predict future outcomes with certainty. Read the in-app [Risk Disclosure](/legal/risk/), [Model Methodology](/legal/methodology/) and [Market Data Notice](/legal/data/) before relying on the service.
